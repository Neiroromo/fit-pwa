# Инструкция для ИИ-агента: как подготовить данные для приложения Fit

Ты читаешь это, потому что пользователь просит тебя составить что-то для своего приложения **Fit**: программу тренировок, меню на несколько дней, список своих упражнений или продуктов. Твой результат — **один JSON-файл**. Пользователь загрузит его в приложении, и данные добавятся к тому, что у него уже есть. Ничего из его старых данных файл не заменяет и не удаляет.

## 1. О приложении (что нужно знать)

- Fit — модульное приложение: **Тренировки** (программы, каталог упражнений, история), **Дневник питания** (приёмы пищи, КБЖУ, вода, планы), **Мониторинг** (вес, замеры, давление).
- Все данные пользователя хранятся только на его устройстве. **Ты не видишь его данные и не можешь ничего записать в приложение сам.** Единственный канал — файл, который ты создаёшь.
- Всё, что создано по твоему файлу, приложение помечает значком «ИИ», а импорт можно целиком отменить одной кнопкой. Поэтому не бойся ошибиться в мелочах, но проверяй числа: пользователь будет им доверять.

## 2. Что ты можешь создать

В файле четыре необязательных раздела (нужен хотя бы один):

| Раздел | Что это | Как попадёт в приложение |
|---|---|---|
| `exercises` | Новые упражнения, которых нет в каталоге | «Мои упражнения» в каталоге упражнений |
| `foods` | Новые продукты и блюда с КБЖУ, которых нет в справочнике | «Мои блюда» в дневнике питания |
| `workouts` | Программы тренировок | Список «Мои тренировки» |
| `mealPlan` | Меню по дням | Приёмы пищи в дневнике, отмечены как **«в плане»** (в итоги дня не входят, пока пользователь не отметит съеденным) |

**Чего делать нельзя:** писать `id` записей, менять или «обновлять» существующее, создавать измерения тела, давление, таблетки, воду, голодание. Этого в файле нет и быть не может.

## 3. Прежде чем составлять, уточни у пользователя

Если пользователь не дал этого сам, задай вопросы коротко, одним сообщением:

- **Тренировки:** цель (масса, сила, похудение, здоровье), уровень (новичок / средний / опытный), сколько дней в неделю и сколько времени на тренировку, где занимается (дом / зал), какое есть оборудование, травмы и ограничения.
- **Меню:** на сколько дней и с какой даты, цель по калориям (или рост, вес, возраст, пол, цель), сколько приёмов пищи, аллергии, продукты, которые не ест, бюджет и время на готовку, кухня.

Если данных мало, а пользователь просит «просто сделай», опирайся на разумные допущения и **напиши их в поле `note`**.

## 4. Формат файла

Кодировка UTF-8, чистый JSON (без комментариев, без хвостовых запятых). Корневой объект:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `format` | строка | **да** | Всегда `"fit-pwa-ai"` |
| `version` | число | **да** | Всегда `1` |
| `generatedBy` | строка | **да** | Название ИИ, например `"ChatGPT"`, `"Gemini"`, `"Claude"`. Показывается пользователю как автор |
| `createdAt` | строка | нет | Дата `YYYY-MM-DD` |
| `note` | строка | нет | Допущения и пояснения для пользователя, до 500 символов |
| `exercises` | массив | нет | см. 4.1 |
| `foods` | массив | нет | см. 4.2 |
| `workouts` | массив | нет | см. 4.3 |
| `mealPlan` | массив | нет | см. 4.4 |

Неизвестные поля игнорируются. Лишние элементы сверх лимитов отбрасываются.

### 4.1. `exercises[]` — новое упражнение (до 100)

Создавай только если упражнения **нет** в каталоге (см. раздел 5).

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| `name` | строка | **да** | 1–80 символов, на языке пользователя |
| `groups` | массив строк | **да** | минимум одна: `chest`, `back`, `shoulders`, `arms`, `abs`, `legs`, `glutes`, `cardio`, `neck` |
| `equipment` | массив строк | нет | из: `body only`, `bands`, `mat`, `exercise ball`, `foam roll`, `pull-up bar`, `bench`, `barbell`, `dumbbell`, `kettlebells`, `cable`, `machine`, `e-z curl bar`, `medicine ball`, `other` |
| `muscles` | массив строк | нет | основные мышцы: `abdominals`, `abductors`, `adductors`, `biceps`, `calves`, `chest`, `forearms`, `glutes`, `hamstrings`, `lats`, `lower back`, `middle back`, `neck`, `quadriceps`, `shoulders`, `traps`, `triceps` |
| `secondary` | массив строк | нет | дополнительные мышцы, те же значения |
| `level` | строка | нет | `beginner`, `intermediate` или `expert` |
| `steps` | массив строк | нет | техника по шагам: до 12 шагов по ≤ 300 символов |

### 4.2. `foods[]` — новый продукт или блюдо (до 300)

Значения — **на 100 г** (для жидкостей на **100 мл**). Описывай продукт, только если его нет в справочнике (см. раздел 5).

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| `name` | строка | **да** | 1–80 символов |
| `unit` | строка | **да** | `"g"` или `"ml"` |
| `kcal` | число | **да** | 0–900 |
| `protein` | число | **да** | белки, г, 0–100 |
| `fat` | число | **да** | жиры, г, 0–100 |
| `carbs` | число | **да** | углеводы, г, 0–100 |
| `fiber` | число | нет | клетчатка, г, 0–100 |
| `sugar` | число | нет | сахар, г, 0–100 |
| `portion` | объект `{size, name}` | нет | типичная порция: `size` в г/мл (1–5000), `name` ≤ 20 символов (`"шт"`, `"ломтик"`, `"порция"`) |

Проверяй: белки + жиры + углеводы не больше 100 г; калории примерно равны `4·белки + 4·углеводы + 9·жиры` (расхождение больше 25 % приложение пометит как подозрительное).
Для готового блюда (суп, салат) считай значения на 100 г **готового** блюда.

### 4.3. `workouts[]` — программа (до 30 тренировок)

Один элемент = одна тренировка (один день программы). Программу на неделю составляй как несколько элементов с понятными названиями: «Пн: грудь и трицепс».

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| `name` | строка | **да** | 1–80 символов |
| `exercises` | массив | **да** | 1–30 упражнений по порядку выполнения |
| `exercises[].name` | строка | **да** | Название упражнения: из каталога (раздел 5) **или** из твоего раздела `exercises` — точно так же написанное |
| `exercises[].sets` | целое | **да** | число подходов, 1–10 |
| `exercises[].comment` | строка | нет | повторения, вес, отдых, ≤ 300 символов (например `"8–12 повторений, отдых 90 с"`) |
| `exercises[].warmup` | boolean | нет | `true`, если первый подход разминочный |

### 4.4. `mealPlan[]` — меню (до 62 дней, до 1000 блюд всего)

Один элемент = один приём пищи одного дня.

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| `date` | строка | **да** | `YYYY-MM-DD` |
| `meal` | строка | **да** | `breakfast`, `lunch`, `dinner` или `snack`. Если у пользователя есть свой приём с другим названием, можно написать это название |
| `items` | массив | **да** | 1–20 позиций |
| `items[].food` | строка | **да** | Название продукта: из справочника (раздел 5) **или** из твоего раздела `foods` — точно так же |
| `items[].amount` | число | **да** | количество в граммах (для жидкостей — в миллилитрах), 1–3000 |

Каждая позиция должна однозначно находиться по названию. Не пиши продукты «в общем» (`"мясо"`): пиши конкретно (`"Говядина тушёная"`) и описывай в `foods`, если такого нет в справочнике.

## 5. Каталоги: что уже есть в приложении

Не выдумывай названия, если упражнение или продукт уже есть. Списки лежат рядом с этой инструкцией:

- Оглавление: [lists.txt](lists.txt)
- Упражнения (1703 шт., по группам мышц): [exercises/legs.txt](exercises/legs.txt), [exercises/chest.txt](exercises/chest.txt), [exercises/back.txt](exercises/back.txt), [exercises/shoulders.txt](exercises/shoulders.txt), [exercises/arms.txt](exercises/arms.txt), [exercises/abs.txt](exercises/abs.txt), [exercises/glutes.txt](exercises/glutes.txt), [exercises/cardio.txt](exercises/cardio.txt), [exercises/neck.txt](exercises/neck.txt)
- Продукты (4756 шт., по категориям): перечень файлов в [lists.txt](lists.txt) (папка `foods/`)

Как пользоваться:
1. Открой нужные файлы (не обязательно все: достаточно групп мышц и категорий, которые понадобятся).
2. Бери названия **точно как в списке** (регистр и знаки препинания не важны, ё = е).
3. Нет подходящего → добавляй в `exercises` или `foods` (поля выше). Не подставляй «похожее» название: приложение сопоставляет по названию целиком.
4. Если ты не можешь открыть списки, составь файл всё равно, а для каждого упражнения и продукта, в названии которых ты не уверен, добавь описание в `exercises` / `foods`. Это безопаснее, чем угадывать.

## 6. Правила качества и безопасности

- Никаких медицинских назначений. Для людей с травмами, беременных, при хронических заболеваниях добавь в `note` рекомендацию посоветоваться с врачом.
- Нагрузка и калории должны быть реалистичны: не больше 10 упражнений и ~90 минут в тренировке без запроса пользователя; калории меню не ниже 1200 (женщины) и 1500 (мужчины) без явной просьбы и предупреждения в `note`.
- Меню: суммируй день и сверь с целью пользователя. Продукты в разных приёмах разнообразь, если не просили иначе.
- Одно и то же упражнение или продукт всегда пиши одинаково во всём файле.
- Язык названий — язык пользователя.

## 7. Как выдать результат

- Если можешь создать файл, создай `fit-ai-YYYY-MM-DD.json`.
- Если не можешь — выведи **только** JSON одним блоком кода (```json), без текста внутри блока. До и после блока можно коротко пояснить, что составлено.
- Не оборачивай JSON в таблицы, не сокращай («...» и «и так далее» недопустимы), не используй комментарии.

## 8. Полный минимальный пример

```json
{
  "format": "fit-pwa-ai",
  "version": 1,
  "generatedBy": "ChatGPT",
  "createdAt": "2026-11-10",
  "note": "Программа на 2 дня для новичка в зале, меню на 1 день около 2200 ккал.",
  "exercises": [
    {
      "name": "Планка на предплечьях с подъёмом ноги",
      "groups": ["abs"],
      "equipment": ["body only"],
      "muscles": ["abdominals"],
      "secondary": ["glutes"],
      "level": "beginner",
      "steps": ["Встаньте в планку на предплечьях.", "Поднимите ногу, удержите 2 секунды, смените ногу."]
    }
  ],
  "foods": [
    {
      "name": "Омлет с сыром",
      "unit": "g",
      "kcal": 190,
      "protein": 12,
      "fat": 14,
      "carbs": 3,
      "portion": { "size": 200, "name": "порция" }
    }
  ],
  "workouts": [
    {
      "name": "День 1: грудь и пресс",
      "exercises": [
        { "name": "Жим штанги лёжа", "sets": 4, "comment": "8–10 повторений, отдых 90 с", "warmup": true },
        { "name": "Планка на предплечьях с подъёмом ноги", "sets": 3, "comment": "по 10 на ногу" }
      ]
    }
  ],
  "mealPlan": [
    {
      "date": "2026-11-11",
      "meal": "breakfast",
      "items": [
        { "food": "Омлет с сыром", "amount": 200 },
        { "food": "Хлеб ржаной", "amount": 40 }
      ]
    }
  ]
}
```

## 9. Чек-лист перед выдачей

1. `format` = `"fit-pwa-ai"`, `version` = 1, указан `generatedBy`.
2. Нет ни одного поля `id`.
3. Все `name` в `workouts[].exercises` и `mealPlan[].items[].food` совпадают с названием из каталога или из твоих `exercises` / `foods`.
4. У каждого нового продукта заполнены `unit`, `kcal`, `protein`, `fat`, `carbs` на 100 г / 100 мл.
5. `sets` — целое от 1 до 10; `amount` — число; даты в формате `YYYY-MM-DD`.
6. JSON валиден, без комментариев и многоточий.
7. В `note` записаны допущения и предупреждения.

## 10. Что дальше делает пользователь

В приложении: **Профиль → Данные на устройстве → Импорт от ИИ** → выбрать файл (или вставить JSON) → просмотреть, что будет добавлено, и подтвердить. Всё добавленное помечено значком «ИИ»; импорт можно отменить целиком.
