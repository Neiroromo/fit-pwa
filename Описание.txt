Описание PWA: 
    Модульный сайт-приложение акумулирующий в себе трекер активности, менеджер тренировок, дневник питания (на данный момент только такой функционал, возможны расширения в будующем). Доступен как для пк так и для мобильных устройств. 

Как работает: 
    Пользователь заходит на основной сайт хостящийся на github и попадает на главную страницу (в дальнейшем - хаб). Для лучшей работы сайт предлагает скачать PWA приложение. Приложение имеет модульную структуру, то есть один пользователь может скачать только разделы "тренировки" и "мониторинг", а другой "активность" и "дневник пиитания". Модули загружаются так же из этого github репозитория.

    P.S. На данный момент мы разрабатываем бета версию, поэтому база данных будет локальной на устройстве, а в дальнейшем планируется интеграция с сервисом google. Пользователь авторизируется через google и база данных сохраняется в его профиле. Нужно продумать архитектуру базы данных и работу с ней так, чтобы переход с локального хранилища в гугл хранилище был максимально безболезненным.

Интерфейс: адаптивный, подходит для пк\планшетов и телефонов. У пк\планшета навигация слева, а у телефона внизу экрана.

Дизайн: минималистичный, темный. 

Навигация: 
    Распологается слева и является статичной, независимо от открытого модуля, содержит в себе список модулей. 
    Модули: хаб (не удаляемый основной модуль), дневник питания, тренировки, активность, мониторинг и другие. При первом открытии (если не найдено локального сохранения) видно только хаб и кнопку "+" по нажатию на которую откроется меню с выбором модулей для скачивания. 
    Модуль на котором сейчас находится пользователь подсвечивается.
    В самом низу находится блок профиля по нажатию на который откроется меню с настройкой профиля.
    Рядом с блоком профиля есть кнопка уведомлений.

Настройки профиля:
    Popup меню в котором можно:
        1. изменить имя и аватарку (только при локальном пользовании)
        2. авторизоваться или выйти из аккаунта google (имя и аватарка подтянутся из этого аккаунта)
        3. настроить модули: откроется второй уровень меню в котором будет список модулей и возможность добавить\удалить\изменить их порядок
        4. подключить подписку (добавим потом)

Модуль Хаб:
    Здесь распологаются виджеты которые пользователь разместил. Изначально экран пустой и есть только кнопка "+", при нажатии на нее открывается меню со списком доступных виджетов. 
    Виджеты разбиты по категориям-модулям. Список виджетов формируется исходя и модулей, которые установлены. 
    Виджеты можно добавлять\удалять\перемещать, для этого в хабе есть кнопка включающая режим редактирования. После ее нажатия подсвечивается сетка (размер зависит от размера экрана) по которой можно перемещать виджеты. 
    Виджеты могут быть разного размера (1х1, 1х2, 2х1, 2х2). Один виджет может иметь как один размер так и несколько, в режиме редактирования и при добавлении виджета можно выбрать размер виджета.

Модуль тренировки:
    1. Календарь (месяц) с отметками когда была тренировка.
        1.1 по нажатию на Календарь он раскрывается и показывается более подробная статистика тренировок. Какие тренировки (названия) и в какие дни были сделаны и сколько занимали по времени.
        1.1.1 Если нажать на тренировку, то отроется список упражнений, какие веса брались\время было затречено, повторы, перерывы.
    2. Кнопка для создания тренировки.
    3. Список созданных тренировок.
        3.1 Для удаления тренировки нужно зажать и потянуть ее влево.
        3.2 У каждой тренировки есть название заданное пользователем
        3.3 У тренировки есть кнопка start, которая запускает данную тренировку и открывает ее окно:
            3.3.1 Сверху название + общий таймер тренировки
            3.3.2 Список упражнений
            3.3.3 У упражнений есть: название, комментарий (после названия, тк могут быть уточнения, которые надо знать сразу)(так же рядом есть кнопка настройки упражнения, при нажатии на которую появится список в котором можно нажать "добавить комментарий"), список сеток (warmup, 1\2\3...(кол-во подходов)).
                3.3.3.1 У каждого сета есть данные за предыдущую тренировку (сколько кг+повторений), кг в эту тренировку (можно изменить), повторений (можно изменить), кнопка отметки "сделал". При отметке что упражнение сделано: если это warmup, то сразу переход к следующему сету, если это сет, то запускается таймер отдыха.
