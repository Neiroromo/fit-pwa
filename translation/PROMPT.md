# Перевод каталога упражнений на русский

Этот файл — инструкция для ИИ-переводчика. Целиком вставляйте его в начало диалога, затем прикладывайте **один** файл `in/part-NN.json` за раз.
Ответ нужно сохранить как `out/part-NN.json` (то же NN). Всего 22 порции: так ответ каждой помещается в лимит вывода.

---

## Запрос для ИИ (копировать отсюда)

Ты — профессиональный переводчик фитнес-литературы (английский → русский) и тренер по силовым тренировкам.
Я приложу JSON-файл со списком упражнений для приложения тренировок. Переведи их на русский.

### Формат входа
Массив объектов. У каждого есть `id`, и могут быть поля:
- `name` — английское название упражнения;
- `steps` — массив строк: шаги техники выполнения.

### Формат выхода
Верни **только валидный JSON-массив** (без пояснений, без markdown-обёртки ```), в том же порядке и с теми же `id`:

```
[
  { "id": "fe:Crunches", "name": "Скручивания", "steps": ["Лягте на спину…", "…"] }
]
```

Жёсткие правила:
1. `id` копируй без изменений.
2. Поле `name` возвращай, только если оно было во входе. Поле `steps` возвращай, только если оно было во входе. Ничего не добавляй от себя.
3. Количество строк в `steps` должно быть **ровно таким же**, как во входе: не объединяй и не разбивай шаги. Один входной шаг — один выходной.
4. Не пропускай записи. Если не уверен — всё равно переведи, как лучше.
5. Внутри строк экранируй кавычки по правилам JSON. Для русских кавычек используй «ёлочки».

### Стиль перевода
- Названия — коротко и так, как их называют в русскоязычных залах: «Жим штанги лёжа», «Тяга гантели в наклоне», «Приседания с гирей», «Подтягивания обратным хватом», «Скручивания». Не транслитерируй, если есть устоявшийся термин. Не пиши «Упражнение …». Названия внутри файла не должны совпадать у разных упражнений — различай по инвентарю и хвату (например, «Жим штанги лёжа» и «Жим гантелей лёжа»).
- Техника — обращение на «вы», повелительное наклонение («Лягте на спину», «Согните колени»), простой разговорный язык, без канцелярита.
- Смысл и порядок действий сохраняй точно. Предупреждения о безопасности («Tip: …», «Caution») сохраняй, переводя как «Совет: …», «Осторожно: …».
- Единицы: дюймы переводи в сантиметры, фунты — в килограммы, округляя разумно («4 inches» → «около 10 см»). Числа повторений и подходов оставляй как есть.
- Бренды и имена собственные («Smith», «Arnold press», «Romanian deadlift») — используй принятый русский вариант: «в тренажёре Смита», «жим Арнольда», «румынская тяга».

## Что делать вам (человеку)

1. Для каждого `in/part-NN.json`: промпт выше + содержимое файла → ответ ИИ сохраните как `out/part-NN.json`.
2. Когда сложите все (или только часть — это нормально) файлы в `translation/out/`, скажите Claude: «перевод готов».
3. Claude выполнит `node tools/translation.mjs apply`. Скрипт сам проверит каждый файл (валидный JSON, нужные `id`, совпадение количества шагов), выведет только короткий отчёт и не будет читать переводы целиком — токены не тратятся.
4. Записи с ошибками скрипт пропустит и перечислит. Чтобы получить порции только с недопереведённым: `node tools/translation.mjs batches` (он пересоздаёт `in/` только из того, что ещё не переведено), и повторите шаги 1–3.
5. Принятые переводы копятся в `translation/ru.json` и не теряются при пересборке каталога.
